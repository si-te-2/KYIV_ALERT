# Географічні дані

Карта використовує адміністративні межі України рівня ADM1. Джерело — geoBoundaries, OpenStreetMap contributors і Wambacher. Для відображення в браузері спрощено контури, перетворено координати та додано українські назви. Збірка містить 27 адміністративних одиниць разом із Києвом, Севастополем та Автономною Республікою Крим. [Вихідний знімок geoBoundaries](https://github.com/wmgeolab/geoBoundaries/tree/9469f09/releaseData/gbOpen/UKR/ADM1)

Похідний файл frontend/src/assets/ukraine-regions.json доступний за [Open Database License 1.0](https://opendatacommons.org/licenses/odbl/1-0/). [Авторство OpenStreetMap](https://www.openstreetmap.org/copyright)

Кольори областей відображають фіксований навчальний сценарій. Поточні повітряні тривоги потребують окремого джерела даних.
