# Географічні дані

Радар показує адміністративні межі України за набором Ukraine COD-AB v05. Обласний шар утворено об’єднанням районних полігонів за батьківським P-кодом. Обидва шари спрощено зі збереженням спільних меж і переведено в одну рівновелику конічну проєкцію. Розміри Одещини, Херсонщини та інших територій визначаються геометрією набору.

На карті є 27 адміністративних одиниць першого рівня й 137 районних або спеціальних територій другого рівня. Окремий запис зони відчуження є в адміністративному наборі. Міста Київ та Севастополь показано на рівні областей. [OCHA / HDX, Ukraine COD-AB](https://data.humdata.org/dataset/cod-ab-ukr) · [Ліцензія CC BY 3.0 IGO](https://creativecommons.org/licenses/by/3.0/igo/)

Інформаційний потік Tryvoha.online публікує обласні та районні стани. Зіставлення районів враховує перейменування, а для окремих громад використовує адміністративну належність із порталу «Децентралізація».
