## Додаткові цивільні попередження

Шар вимкнений за замовчуванням. Для увімкнення задайте `CivilAlerts:MonitoringChannels` як масив або список імен каналів через кому разом із `CivilAlerts:Enabled=true`. Використовуйте джерела, до яких маєте доступ і які публікують окремі цивільні оголошення. Застосунок використовує наявну локальну сесію Telegram.

Приймаються короткі непереслані повідомлення до 500 символів із назвою території та згадкою БпЛА. Розпізнаються назви областей України й поширені регіональні форми, наприклад Одещина, Сумщина, Харківщина. Підтримувані назви міст узагальнюються до відповідної адміністративної території. У результаті зберігаються територія, тип загрози, час публікації та посилання на джерело. Повідомлення про наслідки, роботу ППО, відбій чи навчання відкидаються.

Попередження має пунктирну позначку зі статусом «Потребує перевірки» та посилання на оголошення. Воно зникає через 30 хвилин, після нового офіційного відбою або за втрати з’єднання з офіційним потоком. Підтверджене офіційне оголошення має пріоритет. Браузерні сповіщення з цього шару не надсилаються.

Поточний перелік можна відтворити параметром `CivilAlerts:MonitoringChannels=kyiv_nebo,ppo_kiev,tlknewsua,nebo_raketa,smolii_ukraine,StrategicaviationT,ukraine_pyxx,kpszsu,war_monitor`. Параметр зберігайте в локальних user-secrets або змінних середовища. Результат аналізу ключових слів може бути помилковим. Час у картці означає час допису.

## Telegram Bot API

Для інтеграції через Telegram Bot API потрібен бот із власним токеном і доступ до відповідного каналу. Власник або адміністратор каналу додає бота, після чого можна перевірити надходження нових публікацій у дозволеному тестовому середовищі. Токен налаштовується локально через змінну середовища, без додавання до Git. [Telegram Bots FAQ](https://core.telegram.org/bots/faq#what-messages-will-my-bot-get)
