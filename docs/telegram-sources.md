Список містить запропоновані джерела. Локальна DEMO-версія показує посилання і повертає статус PENDING_ACCESS через /api/status. Моніторинг і доставка повідомлень вимкнені. Географічні позначки на радарі походять із навчального сценарію.

Для інтеграції через Telegram Bot API потрібен бот із власним токеном і доступ до відповідного каналу. Власник або адміністратор каналу додає бота, після чого можна перевірити надходження нових публікацій у дозволеному тестовому середовищі. Токен налаштовується локально через змінну середовища, без додавання до Git. [Telegram Bots FAQ](https://core.telegram.org/bots/faq#what-messages-will-my-bot-get)
