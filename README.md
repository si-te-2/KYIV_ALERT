# KYIV ALERT

Локальний вебрадар цивільних повітряних тривог. Радар відкривається після вибору області або міста та зберігає вибір у цьому браузері. Для міст без окремої адміністративної одиниці застосовуються сповіщення відповідної області.

## Запуск

Потрібні .NET SDK 10 і Node.js 22.12+ або 24 LTS для збирання фронтенду.

```powershell
./scripts/build.ps1
dotnet run --project backend/KyivAlert.Api
```

Відкрийте [локальний сайт](http://127.0.0.1:5080/). ASP.NET Core обслуговує зібраний фронтенд на localhost. Ручні команди для Linux і macOS наведено в [інструкції](docs/local-development.md).

## Радар і сповіщення

- Карта охоплює 27 адміністративних одиниць. Кольори та пульсуючі позначки вказують на цивільні сповіщення по регіонах.
- Кнопка «Запустити тест» окремо запускає навчальне підсвічування для обраного регіону.
- Кнопка «Увімкнути сповіщення» запитує дозвіл браузера. Десктопні сповіщення з’являються при зміні рівня загрози для обраного регіону, поки сайт відкрито. Перше завантаження показує поточні дані на картці без повторного сповіщення про наявну подію.
- Коли даних для регіону немає або їх не вдалося оновити, радар показує «Стан невідомий». Офіційна мапа доступна за посиланням у шапці.

## Налаштування джерел на сервері

- Для Києва та Київщини використовується локальна Telegram-сесія. [Інструкція входу](backend/KyivAlert.Telegram/README.md). Увімкнення під час запуску показано нижче.
- Для загальноукраїнського потоку задайте токен як змінну середовища `CivilAlerts__NationalApiToken` лише на сервері. [Документація постачальника](https://devs.alerts.in.ua/developers).
- Публічний API повертає регіон, рівень тривоги та час, якщо він відомий. Назви каналів і посилання на дописи відсутні у відповідях.
- Токени, паролі, Telegram session-файли та приватні ключі зберігаються поза Git. Файл .env.example містить шаблони.

```powershell
dotnet run --project backend/KyivAlert.Api -- --CivilAlerts:Enabled=true
```

## Перевірки

```sh
dotnet build backend/KyivAlert.Api/KyivAlert.Api.csproj -c Release
dotnet test backend/KyivAlert.Tests/KyivAlert.Tests.csproj -c Release
npm --prefix frontend ci
npm --prefix frontend run build
npm --prefix frontend test
```

GitHub Actions запускає збірки, тести та HTTP-перевірку. Національний потік перевіряється на тестових даних, тому для CI не потрібен доступ до реальних джерел.

## Структура

- `backend/` — ASP.NET Core API, доменні контракти, демонстраційні дані, модуль Telegram і тести.
- `frontend/` — React, TypeScript, Vite і Tailwind CSS.
- `docs/` — інструкції й авторство географічних даних.

[Географічні дані й авторство](docs/map-data.md)

Фонове зображення `frontend/src/assets/kyiv-dusk.jpg` згенеровано через ImageGen за описом «панорамний вид вечірнього Києва та Дніпра, індигове небо, тепла смуга заходу сонця, освітлені набережні».
