# KYIV ALERT

Локальний вебрадар цивільних повітряних тривог. Радар відкривається після вибору області, міста або району та зберігає вибір у цьому браузері. Для міст використовується доступний стан їхнього району або області.

## Запуск

Потрібні .NET SDK 10 і Node.js 22.12+ або 24 LTS для збирання фронтенду.

```powershell
./scripts/build.ps1
dotnet run --project backend/KyivAlert.Api
```

Відкрийте [локальний сайт](http://127.0.0.1:5080/). ASP.NET Core обслуговує зібраний фронтенд на localhost. Ручні команди для Linux і macOS наведено в [інструкції](docs/local-development.md).

## Радар і сповіщення

- Шар **DRONE THREAT RADAR** показує окрему позначку для кожної території з підтвердженим попередженням. Поточні Telegram-джерела покривають Київ і Київську область. Відкрийте картку позначки, щоб переглянути територію, тип, час і першоджерело. Шари «Тривоги» й «БпЛА» перемикаються окремо.
- Червона позначка Shahed з’являється, якщо офіційне оголошення прямо називає цей тип БпЛА. У бічній панелі натисніть «Лише Shahed», щоб відфільтрувати карту й список. Загальні оголошення про загрозу БпЛА залишаються доступними в режимі «Усі БпЛА».
- Необов’язковий шар повідомлень з інших Telegram-джерел має статус «Потребує перевірки» і пунктирну позначку. Згадки про Київ і населені пункти Київщини узагальнюються до Києва або Київської області. [Налаштування джерел Telegram](docs/telegram-sources.md).
- Карта показує області й райони. Перетягуйте її мишею або пальцем, або натискайте стрілки після фокусування карти. Для масштабу використовуйте кнопки, Ctrl або ⌘ із колесом чи жест двома пальцями. Кнопки та жест двома пальцями також дають змогу повертати карту.
- «Стрічка тривог» відкриває панель праворуч із пошуком територій, поточними тривогами й змінами, які надійшли після відкриття сторінки. Натисніть запис, щоб відкрити територію на карті. Пульсуючу позначку теж можна натиснути, щоб побачити стан території та час, якщо він відомий.
- Кнопка «Запустити тест» окремо запускає навчальне підсвічування для обраного регіону.
- У «Налаштуваннях» можна підписатися на додаткові області, увімкнути або вимкнути сповіщення. Браузер запитує дозвіл. Сповіщення працюють, поки сайт відкрито. Початковий знімок і повторні оновлення того самого стану не створюють сповіщень. Якщо для регіону є повітряна тривога, вона має пріоритет.
- Коли даних для регіону немає або їх не вдалося оновити, радар показує «Немає даних». Над картою є попередження про затримки й можливі помилки та посилання на офіційну мапу повітряних тривог.
- [Зміни та перевірки KYIV ALERT 2.0](docs/kyiv-alert-2.md). Сторінки конфіденційності й відмови від відповідальності відкриваються з підвалу сайта.

## Налаштування джерел на сервері

- Для потоку областей і районів запускайте сервер із параметром CivilAlerts:PublicFeed=true. Дані оновлюються кожні 45 секунд. Реєстрація не потрібна. Це інформаційний сервіс. Для підтвердження використовуйте офіційну мапу або вказівки місцевих служб. [Документація потоку](https://tryvoha.online/api)
- «Тривоги немає» відображається лише для територій із доступним станом відбою або без активного оголошення в повному свіжому знімку. За відсутності покриття, прострочених або неповних даних показується «Немає даних».

- Для Києва та Київщини використовується локальна Telegram-сесія. [Інструкція входу](backend/KyivAlert.Telegram/README.md). Увімкнення під час запуску показано нижче.
- Для загальноукраїнського потоку задайте токен як змінну середовища `CivilAlerts__NationalApiToken` лише на сервері. [Документація постачальника](https://devs.alerts.in.ua/developers).
- `/api/civil-alerts` повертає регіон, рівень тривоги та час, якщо він відомий. `/api/drone-warnings` окремо повертає статус джерела й регіональні попередження з посиланнями на прийняті оголошення.
- Токени, паролі, Telegram session-файли та приватні ключі зберігаються поза Git. Файл .env.example містить шаблони.

```powershell
dotnet run --project backend/KyivAlert.Api -- --CivilAlerts:Enabled=true
```

## Перевірки

```sh
dotnet build backend/KyivAlert.Api/KyivAlert.Api.csproj -c Release
dotnet test backend/KyivAlert.Tests/KyivAlert.Tests.csproj -c Release
npm --prefix frontend ci
npm --prefix frontend run build
npm --prefix frontend test
```

GitHub Actions запускає збірки, тести та HTTP-перевірку. Національний потік перевіряється на тестових даних, тому для CI не потрібен доступ до реальних джерел.

## Структура

- `backend/` — ASP.NET Core API, доменні контракти, демонстраційні дані, модуль Telegram і тести.
- `frontend/` — React, TypeScript, Vite і Tailwind CSS.
- `docs/` — інструкції й авторство географічних даних.

[Географічні дані й авторство](docs/map-data.md)

Фонове зображення `frontend/src/assets/kyiv-dusk.jpg` згенеровано через ImageGen за описом «панорамний вид вечірнього Києва та Дніпра, індигове небо, тепла смуга заходу сонця, освітлені набережні».
