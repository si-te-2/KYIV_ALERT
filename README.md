# KYIV ALERT

Локальна DEMO-панель для майбутньої системи аналізу повідомлень про загрози для Києва.

## Поточна версія

Етап 1 завершено мінімальною робочою версією. ASP.NET Core API повертає стан системи та синтетичне повідомлення. React-панель показує DEMO MODE, зупинений моніторинг, стан Telegram, джерела й історію. При втраті API вона показує втрату з’єднання та позначає попередні дані.

Демонстраційний аналізатор має статус STOPPED, Telegram — NOT_CONFIGURED. Увімкнення `DemoMode=false` зупиняє запуск із помилкою. База даних, бот, аналізатор, SignalR, авторизація адміністратора, звук, PWA та Web Push заплановані наступними етапами. У цій версії API лише читає локальні DEMO-дані.

## Запуск

Потрібні .NET SDK 10, Node.js 22.12+ або 24 LTS для frontend-збірки та PowerShell 7. Виконайте з кореня репозиторію.

```powershell
./scripts/build.ps1
dotnet run --project backend/KyivAlert.Api
```

Відкрийте [локальну панель](http://127.0.0.1:5080). ASP.NET Core обслуговує результат Vite-збірки. Сервер слухає 127.0.0.1. Після змін frontend повторіть build. Для завершення натисніть Ctrl+C.

Ручні команди для Linux/macOS наведені в [інструкції](docs/local-development.md).

## Радар і джерела

Головне меню відкриває огляд, [радар](http://127.0.0.1:5080/#/radar), налаштування карти та «Що нового». На радарі можна збільшити карту, перейти до Києва та вибрати один із 27 регіонів. Позначки тривог є навчальними. Налаштування зберігаються в браузері. [Географічні дані й авторство](docs/map-data.md)

Кнопка «Запустити тест» підсвічує Київ, Київську і Чернігівську області та показує сповіщення на сторінці. Кнопка «Завершити тест» показує навчальний відбій. Поточний стан повітряних тривог доступний на [офіційній мапі](https://map.ukrainealarm.com/).

Сім каналів Telegram додано до переліку джерел зі статусом «Очікує доступу». [Доступ і список каналів](docs/telegram-sources.md)

## Перевірки

```sh
dotnet build backend/KyivAlert.Api/KyivAlert.Api.csproj --configuration Release
dotnet test backend/KyivAlert.Tests/KyivAlert.Tests.csproj --configuration Release
npm --prefix frontend ci
npm --prefix frontend run build
npm --prefix frontend test
```

GitHub Actions виконує збірку, тести й HTTP-перевірку зібраної панелі. Локально перевірено збірки C# та React, 18 xUnit і 2 frontend-тести.

## Конфігурація

.env.example містить порожні шаблони для наступних етапів. ASP.NET Core читає змінні середовища. Файли .env автоматично не завантажуються. Токени, паролі, Telegram session-файли та ключі зберігайте локально. .gitignore виключає типові секретні файли й результати збірки.

[План розробки](docs/roadmap.md) визначає наступні етапи.

Ліцензія очікує погодження власника.

## Локальний вхід у Telegram

Підготовлено окрему команду MTProto для входу у власний акаунт.

```powershell
./scripts/connect-telegram.ps1
```

Номер телефону, код Telegram і пароль 2FA вводяться у локальному інтерактивному терміналі. Перед запуском налаштуйте локальні реквізити застосунку за [інструкцією модуля](backend/KyivAlert.Telegram/README.md). Авторизацію підтверджує власник акаунта. Створена сесія зберігається у профілі користувача. Сайт продовжує працювати в DEMO MODE.

```sh
dotnet run --project backend/KyivAlert.Telegram -- --check-config
```

Ця перевірка підтверджує наявність і формат реквізитів локально. Їх прийняття Telegram перевіряється під час входу.

## Офіційні повідомлення для Києва та Київщини

Радар може переглядати останні оголошення про повітряну тривогу та відбій із публічних каналів [КМВА](https://t.me/VA_Kyiv) та [Київської ОВА](https://t.me/kyivoda). Для локального запуску встановіть `CivilAlerts__Enabled=true` у середовищі або передайте аргумент `--CivilAlerts:Enabled=true`. Потрібна наявна локальна сесія з розділу вище. За замовчуванням моніторинг вимкнено.

```powershell
dotnet run --project backend/KyivAlert.Api -- --CivilAlerts:Enabled=true
```

Радар перевіряє канали кожні 45 секунд. На карті відображаються лише повідомлення про Київ та Київську область. Оголошення для окремого району позначається як тривога в частині області. Відбій для одного району не означає відбій для всієї області. Якщо повідомлення за останні 48 годин не вдалось розпізнати, або джерело недоступне, відображається «Стан невідомий». Кожна картка посилається на оригінальний допис і показує час його публікації. За поточним станом також можна звернутися до [офіційної мапи](https://map.ukrainealarm.com/).
